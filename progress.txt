## Codebase Patterns
- 后端代码在 `backend/`，启动命令必须在 backend 目录下执行：`python -m uvicorn app.main:app --host 127.0.0.1 --port 8010`
- **后端端口固定为 8010**（本机 8000 被 Windows 系统服务 svchost.exe 占用，绑定会报 WinError 10013，不要用 8000）
- 每个资源一个路由文件：`backend/app/routers/<name>.py`，统一前缀 `/api/v1/<name>`；各路由专属的 Pydantic 请求/响应模型**定义在路由文件内部**，避免多个 worker 并行改 `schemas.py` 造成冲突
- 数据库：SQLite，文件在 `backend/data/kefu.db`（已 gitignore）；ORM 用 SQLAlchemy 2.0 `Mapped` 风格；启动时 `init_db()` 自动建表，无需迁移工具
- 种子数据：`backend/scripts/seed.py`（幂等，可重复执行）；执行方式 `cd backend && python scripts/seed.py`
- 前端将放 `frontend/`（Vite+Vue3+Element Plus），dev server 端口 5173，`vite.config.js` 中 `/api` 代理目标为 `http://127.0.0.1:8010`
- 本机 Python 3.12 位于 `C:\Python312`，`python` 命令直接可用；npm 可用（Node v24）
- 健康检查端点：`GET /api/v1/health`
- **cmd 下 curl 带中文查询参数会乱码/空响应，必须 URL 编码**（如 退款 → %E9%80%80%E6%AC%BE）；POST/JSON body 里的中文在 cmd 里也可能出问题，尽量用 ASCII 或临时 .py 脚本
- **同一 cmd 命令行里用 `&` 并行执行 curl 时存在竞态**（如 DELETE 与 PUT 同一 id），串行测试写入/修改类操作
- 标签精确匹配技巧：`func.concat(",", Script.tags, ",").like(f"%,{tag},%")` 避免"催"误匹配"催办"
- 停止 uvicorn：`for /f "tokens=5" %a in ('netstat -ano ^| findstr :8010 ^| findstr LISTENING') do taskkill /F /PID %a`
